# ABC Executive Summary & Profitability Dashboard

## 📊 Project Overview

This project focuses on analyzing business sales and profitability data using **Microsoft Excel** to create an interactive Executive Summary Dashboard.

The dashboard provides insights into revenue trends, gross profit, business performance, country-wise sales, regional comparisons, and sales channel contributions.

## 🎯 Project Objectives

- Monitor key business performance indicators (KPIs).
- Analyze monthly revenue and gross profit trends.
- Identify the top 5 revenue-generating countries.
- Evaluate revenue contribution by sales channel.
- Compare performance across different regions.
- Visualize country-wise revenue distribution.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Data Cleaning and Preparation
- Pivot Tables
- Pivot Charts
- KPI Cards
- Excel Slicers
- Map Charts
- Data Visualization
- Business Analysis

## 📊 Dashboard Features

1. **Monthly Revenue & Profit:** Tracks monthly revenue and gross profit trends.
2. **Top 5 Countries by Revenue:** Identifies the highest revenue-generating countries.
3. **Revenue Share by Channel:** Compares revenue contribution across sales channels.
4. **Region-wise Comparison:** Analyzes revenue distribution across regions.
5. **Country-wise Map Chart:** Visualizes geographical revenue performance.
6. **Interactive Slicers:** Enables dynamic filtering by Product Category, Country, and Quarter.

## 📂 Project Workflow

2. Data Cleaning and Preparation

Developed an interactive Excel Dashboard that transforms raw sales data into meaningful business insights, helping users monitor financial KPIs, evaluate profitability, and compare performance across different business dimensions.
